# 概要

**麻雀独立リーグ記録**（仮称）は、身内・コミュニティ単位で開催する麻雀リーグの対局結果を記録し、参加者の成績・順位を閲覧できる Web アプリケーション。

## 目的

紙やスプレッドシートで管理されがちな身内麻雀リーグの集計を、Web アプリ上で一元管理できるようにする。リーグ管理者は対局結果を入力するだけで、参加者の累積成績・順位が自動で算出・共有される状態を目指す。

## 想定ユーザー

| 役割 | 認証 | できること |
|---|---|---|
| **Owner**（リーグ管理者） | 必要（**招待制**によるアカウント登録） | リーグの作成、プレイヤー登録、対局結果の入力・編集、他の Owner の招待 |
| **Viewer**（閲覧者） | 不要（URL共有） | リーグページの閲覧（成績・順位） |

- **Player**（対局者）はアプリのアカウントを持たない。Owner がリーグ内に「名前」として登録するだけで成立する。
- 1 つのリーグに対し Owner は 1 人（暫定。複数 Owner / 共同管理は後続検討）。

## スコープ

### 対応する麻雀形式

- 4 人麻雀 / 3 人麻雀 の両方
- 半荘戦 / 東風戦 の両方
- 形式（人数・戦形式）は **リーグ単位で固定** とする。同一リーグ内に「4 人麻雀の半荘」と「3 人麻雀の東風」を混在させない。

### MVP に含める機能

- リーグの作成（名前・形式の指定）
- リーグへのプレイヤー登録
- 対局（半荘 or 東風 1 回分）の最終点数入力
- 個人ごとの成績集計（合計点、平均点、対局数 等）
- リーグ内の順位表示
- リーグページの URL 共有による閲覧（認証不要）

### スコープ外（現時点）

- 詳細なルールセット管理（ウマ・オカ・チップ・順位点など）→ 後続フェーズで検討
- 1 局単位（和了 / 放銃 / 役）の記録
- 自動採点・点棒計算
- Player 側のアカウント機能、リーグ参加申請
- コメント・チャット・SNS 連携
- 複数リーグをまたぐ統計

## 主要ユースケース（概要）

1. **リーグを作る** — Owner がリーグを作成し、形式（人数・戦形式）を決める
2. **プレイヤーを登録する** — リーグに参加するプレイヤーの名前を追加する
3. **対局結果を入力する** — 1 半荘（or 1 東風）終わるごとに、各プレイヤーの最終持ち点を入力する
4. **成績を見る** — 累積成績・順位がリーグページに表示される
5. **URL を共有する** — Viewer に URL を渡せば、認証なしで成績を閲覧できる
